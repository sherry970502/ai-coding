# v0.3 研发版本说明 —— 透明、可控、能恢复

本版主题来自 2026-10 用户反馈（归纳见 `docs/feedback-2026-10.md`）：用户最大的三类痛点是**等待不透明、消耗不透明、失败了救不回来**。v0.3 延续「交互完整、mock 先行」的节奏，以下按功能列出实现与 mock 边界。

## 1. 积分账本与计费透明（`lib/credits.ts`、`components/CreditsDrawer.tsx`）
- 顶栏常驻余额「⚡ N」，点开：余额、三条承诺（事前可见预估 / 失败不扣 / 实际与预估差 ≤40%）、计费规则表、消耗明细流水。
- 预估消耗：对话免费、视觉方向 ~5、整体制作 ~40、方案改造 ~30、快速修改 ~8、体检 ~2；实际按产出字符数在 ±40% 内浮动。
- 失败记一笔 `cost: 0, status: "failed"` 流水，让「失败不扣」看得见。
- **mock 边界**：账本存 localStorage（`aps.credits.v1`），初始 500 分、可领体验积分。真实计量应由后端按 token 结算，前端只展示；规则数值上线前需按真实成本标定。

## 2. 进度与预估时长（`components/BuildProgress.tsx`、PreviewPane 的 PatchOverlay）
- 制作页：预估剩余时间倒计时 + 阶段文案 + 本次预估消耗；快速修改遮罩同样显示预估时间。
- 预估来源：`aps.durations.v1` 记录本机最近 5 次各类操作的真实耗时取均值，无历史用默认值。
- **mock 边界**：真实实现应由服务端按需求规模给预估（反馈明确要求"按需求给出预估制作时间"），本版用历史耗时近似。

## 3. 失败恢复（Studio `BuildFailure`）
- 构建/修改失败：弹层显示失败原因、保留完整修改要求（指令 + 点选元素），一键「原样重试」，并明示未扣积分。
- **mock 边界**：重试是整次重跑。真正的断点续作（从中断 token 处续写）需要后端保存生成现场，列入 v0.4。

## 4. 修改清单：多处小改合并（PreviewPane `queue`）
- 编辑模式点选元素 →「＋加入清单」攒多处 →「一次改完 N 处」，合并为一次 patch 构建、按一次计费。
- 指令拼装为「修改点 1/2/3…」，工程师提示词已加"逐条执行、互不影响、不顺手重构"约束。

## 5. 产品体检（`app/api/qa/route.ts`、`QA_SYSTEM`）
- 预览工具栏「🩺 体检」：验收工程师读完整 HTML，输出大白话问题清单（标题/表现/严重程度/修复指令，JSON Schema 约束），支持单条修复或一键修复全部（合并一次计费）。
- 检查清单直接取自真实用户报障类型：重叠遮挡、点不动的按钮、空红点、图表异常、乱码、未适配手机。
- **mock 边界**：静态代码审查，不是真实运行时测试；上线后可叠加无头浏览器跑真实快照。演示项目预置示例报告（`DEMO_QA`）。

## 6. 版本恢复显性化（PreviewPane 历史菜单）
- 旧版本行加「⟲ 恢复」（把旧版推为新的最新版，免费，历史不丢）；查看旧版本时显示黄色横幅（恢复 / 回到最新）。

## 7. 需求输入增强（ChatPanel 附件、PM_SYSTEM）
- 📎 附件：txt/md/csv/json 读入全文（≤5 万字）随消息发送，展示折叠为「📎 已附上《文件名》」；PDF/Word/图片提示"识别支持中，请先贴文字"。
- PM 提示词：参考材料/竞品要点提取；批量需求逐条编号复述（采纳/调整/暂不做）再出方案。
- **mock 边界**：附件全文直接进对话上下文；超长文档应走后端解析/摘要，PDF/Word/OCR 需文档解析服务。

## 8. 平台能力自动开启（`recommendedServices`）
- PM 方案 JSON 新增 `recommendedServices: [{id, reason}]`（0~3 项）；确认方案时自动开通（含依赖联动），toast 告知，方案卡能力行显示「方案推荐」徽标 + 原因。
- 直接回应反馈：「能力词出现在对话里但没帮我选上，发布页之前不知道是什么」。

## 9. 发布：暂停访问（PublishPanel）
- `PublishState.status` 新增 `"paused"`；已上线产品可「⏸ 暂停访问」（项目/数据/链接保留，访客见暂停页），随时「▶ 恢复访问」。
- **mock 边界**：真实实现是网关层开关；工作台仪表盘对 paused 项目暂按未上线展示，后续可补状态徽标。

## 其他
- 设计师提示词：三个视觉方向的说明需帮助选择（"适合谁/什么场合"），回应「风格差异不够大、缺说明」。
- 工程师提示词：颜色/样式修改按字面精确执行，回应「调颜色多次解读出错」。
- 模型档位：设置里已有三档模型；计费规则中写明"更强模型消耗更高"，回应「标准版希望可选高阶模型」。

## 验证
- `tsc --noEmit`、`next build` 通过；本地 `next start` 冒烟：首页/项目页 200，`/api/qa` 链路通（本机受限凭证返回 503 时错误路径文案可读）。
- 本机无法做真实 API 冒烟（环境凭证仅允许 Claude Code 客户端），生成链路请在配置了正常 `ANTHROPIC_API_KEY` 的环境验证。
