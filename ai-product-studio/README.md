# 造物工坊 · AI Product Studio

不懂技术也能做产品的网页工具：与 AI 产品经理对话明确需求 → 挑选视觉方向 → 后台自动编码 → 直接体验成品，点选即改、对话迭代。

## 快速开始

```bash
cd ai-product-studio
npm install

# 方式一：配置服务器 Key（推荐）
echo 'ANTHROPIC_API_KEY=sk-ant-xxxx' > .env.local

npm run dev
# 打开 http://localhost:3000
```

方式二：不配环境变量，启动后点右上角「⚙ 设置」填入你的 Anthropic API Key（只保存在浏览器 localStorage，随请求头发给本地服务转发）。

## 使用流程

> 顶部步骤条支持随时点击回看：已完成的步骤可以回去查看和调整（方案清单、平台能力、视觉方向），改动会在下次修改产品时生效；已有成品时确认新方案会在现有产品上改造，不会推倒重来。

1. **需求与方案** —— 左侧告诉产品经理你想做什么。TA 会追问 1~2 轮，然后产出方案卡片（目标用户 / 核心价值 / 功能模块 / 标准确认清单：数据保存、多端适配、离线可用、分享导出）。逐项确认后进入下一步。
2. **视觉设计** —— AI 设计师给出 3 个气质不同的视觉方向（配色 / 字体气质 / 圆角，带迷你预览）。不满意可一句话调整后"换一批"。
3. **制作中** —— 编码过程对你不可见，只看到进度。约 1~2 分钟产出一个完整的单文件网页应用（数据存在浏览器本地，下载后双击即用）。
4. **体验与迭代**
   - **编辑模式**：点工具栏「✎ 编辑模式」，再点页面上任意元素。纯文字修改立即生效；复杂修改一句话交给 AI。
   - **流程调整**：在左侧对话框继续和产品经理聊，TA 更新方案，你确认后产品自动按新方案改造。
   - **迭代建议**：每个版本交付后自动给出 4 个建议，点击或按 `⌘1`~`⌘4` 直接执行。
   - 其它：手机/电脑视图切换、版本历史回退、`⌘K` 聚焦对话框、下载成品 HTML。
5. **发布上线**（当前为产品原型：交互完整，部署/打包为流程演示，见 `docs/shipping.md`）
   - **产品出口**：网页 Web 一键发布（草稿与线上分离，可更新/回滚）、手机 H5 扫码、安卓 APK 打包、微信小程序接入说明（`docs/miniprogram.md`）、iOS 规划占位。
   - **平台服务**：方案阶段与发布阶段均可勾选——账号体系（微信/Google/手机号）、云端数据、AI 能力（平台签发专属 Key、可选模型）、积分钱包（真实收款规划中）、访问统计。勾选的服务会在生成的产品中以本地模拟形式呈现。
   - **进阶**：外接自有云（腾讯云/阿里云/Railway）入口与指引。

## 架构

- Next.js 14（App Router）+ TypeScript，无额外 UI 依赖
- `@anthropic-ai/sdk`，默认模型 `claude-opus-4-8`（设置里可切换角色模型）
- API 路由：
  - `POST /api/pm` —— 产品经理对话（流式；方案以 `<proposal>JSON</proposal>` 内嵌返回，前端解析成卡片）
  - `POST /api/styles` —— 视觉方向（structured outputs 保证 JSON）
  - `POST /api/build` —— 生成 / 改版 / 点选修补，流式输出完整单文件 HTML
  - `POST /api/suggest` —— 迭代建议
- 成品在 iframe（sandbox）中预览；注入的编辑脚本通过 postMessage 实现"点选元素 → 修改"
